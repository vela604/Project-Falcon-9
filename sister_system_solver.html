Sister Systems Solver

α(t) = A·sin(f·t + k₁) + k₂  with  f = 2π/P  —  rotational (j = 1) and linear (j = 2), sharing one final time T₀ = L.

1 · Model and boundary conditions

For each system j the acceleration follows the same shape, only the symbols differ:

αⱼ(t) = Aⱼ · sin(fⱼ t + k₁ⱼ) + k₂ⱼ , fⱼ = 2π / Pⱼ j = 1 (rotational) : a₀ = α₀ , v₀ = ω₀ , Δs = θ_f − θ_i j = 2 (linear) : a₀ = a₀ , v₀ = v₀ , Δs = s_f − s_i

Known: a₀ⱼ, v₀ⱼ, Δsⱼ and the common final time L = T₀.
Unknown: Aⱼ, k₁ⱼ, k₂ⱼ, Pⱼ.

Boundary conditions (identical for both systems):

t = 0 : α(0) = a₀ , ω(0) = v₀ , s(0) = s_i t = L : α(L) = 0 , ω(L) = 0 , s(L) = s_f ⇒ s(L) − s(0) = Δs

2 · First and second integrals

ω(t) = v₀ + (A/f)·[ cos k₁ − cos(ft + k₁) ] + k₂·t s(t) − s(0) = v₀t + (A/f)·[ t·cos k₁ − ( sin(ft + k₁) − sin k₁ ) / f ] + ½ k₂ t²

3 · The key reduction

Put m = f·L/2 = πL/P. Combining the four conditions α(0)=a₀, α(L)=0, ω(L)=0, s(L)−s(0)=Δs collapses everything into one transcendental equation in m:

g(m) ≡ 1/m² − cot(m)/m = Λ , Λ = 2·(2Δs − v₀·L) / (a₀·L²)

Once m is known, every constant is explicit:

B = 1 + 2v₀/(a₀L) , D = cot m − 1/m R = tan(k₁ + m) = − B / D φ ≡ k₁ + m = atan2(−B , D) A = − a₀ / ( 2·sin m · cos φ ) k₂ = ½·a₀·( 1 + R·cot m ) P = π·L / m (the period) f = 2m / L = 2π/P

4 · Branch structure of g(m)

g is strictly increasing on every interval (nπ, (n+1)π):

  • Branch n = 0 — the physical first branch, m ∈ (0, π): g rises from 1/3 to +∞. A solution exists iff Λ > 1/3, and it is unique.
  • Branches n ≥ 1 — higher harmonics: g runs from −∞ to +∞, so a solution exists for every L > 0 (but the period P = πL/m becomes short).

5 · The valid range of T₀ (first branch)

For branch n = 0 the condition Λ > 1/3 is equivalent to

Q(L) = a₀·L² + 6·v₀·L − 12·Δs having the opposite sign to a₀ ⟺ L lies strictly between the two roots of Q ⟺ discriminant 9v₀² + 12·a₀·Δs > 0

Both roots exist only if the discriminant is positive; then L ∈ (max(0, r_lo), r_hi). The shared range is the intersection of the two systems' intervals.

Equivalent parametrization. Since only tan(k₁+m) is fixed, the pair (A, k₁) → (−A, k₁ + π) satisfies the same four equations (k₂ unchanged) — but A·sin(ft + k₁) is invariant under it, so both representations give the same acceleration waveform. It is a reparametrization, not a new physical solution.
Excluded case. a₀ = 0 makes the formulas degenerate (division by a₀). That special branch was handled separately and is not solved here.

9 · What this tool does (and what you said)

The setup

You have a rotational angular-acceleration law α(t) = A sin(f t + k₁) + k₂ with f = 2π/T, and a sister equation of exactly the same shape for linear motion. None of A, k₁, k₂, T is known. What is known is the state at the start — α(0) = α₀, ω(0) = ω₀, θ(0) = θ_i — and the state at the end T₀: the acceleration and velocity have both died to zero and the displacement has reached θ_f.

The procedure carried out above

  1. Integrate α(t) once → an expression for ω(t) containing ω₀ and the constants.
  2. Integrate again → an expression for θ(t) containing θ_i and ω₀.
  3. Impose the end conditions α(T₀)=0, ω(T₀)=0, θ(T₀)=θ_f together with α(0)=α₀. This yields a set of relations linking every unknown to the knowns.
  4. Eliminate k₁ by introducing m = πT₀/T and R = tan(k₁+m). Everything collapses to a single equation for m: 1/m² − cot(m)/m = Λ, with Λ = 2(2Δs − v₀T₀)/(a₀T₀²).
  5. Solve for m with safeguarded Newton–Raphson on the chosen branch.
  6. Back-substitute to get the period P = πT₀/m, then k₁, A, k₂ explicitly.

The twist you raised: T₀ is not free

Because T₀ is shared by both sister systems, it cannot be picked arbitrarily — it must sit inside the admissible window of both of them simultaneously. On the first physical branch the window for each system is the interval between the roots of a₀L² + 6v₀L − 12Δs, and the shared window is the intersection. Section 7 computes it; section 8 refuses to solve outside it.

The results

m = π·T₀ / P (solved from g(m) = Λ) B = 1 + 2v₀/(a₀T₀) D = cot m − 1/m R = −B/D = tan(k₁ + m) φ = k₁ + m = atan2(−B, D) A = −a₀ / (2 sin m cos φ) k₂ = ½ a₀ (1 + R cot m) P = π·T₀ / m , f = 2π/P = 2m/T₀

Each result block also shows residuals for α(0)−a₀, α(L), ω(L) and s(L)−s(0)−Δs, which should all be numerically zero — a direct check that the solution is genuine.

  • Normalized displacement overlay — (s(t) − s(0)) / Δs vs t/L for both systems. Both curves start at 0 and end at 1; if the shapes are different it is because the two sisters had different (a₀, v₀, Δs) triples and hence different (mⱼ, Pⱼ).

Notes

  • Branch n = 0 is the physical one and gives a finite T₀ window. Branches n ≥ 1 are higher harmonics: always solvable, arbitrarily short period.
  • a₀ = 0 is a degenerate case (the shape of the equation changes) and is excluded here.
  • If |cot m − 1/m| → 0 the amplitude blows up; the solver flags this.
  • Charts are redrawn on every solve; changing the T₀ range clears them (old results are stale).
