Monotonic / Single-Crossing Sinusoidal Solver

A more flexible acceleration model that guarantees at most one zero-crossing before the final time.

1 · Why the old model fails

The previous form α(t) = A sin(ft + k₁) + k₂ is rigid: for a₀ = 1.7301, v₀ = −5.4537, Δs = −15.966 the discriminant 9v₀² + 12a₀Δs < 0, so no valid T₀ exists on the physical branch — even though physically a smooth solution clearly exists.

2 · New form

We allow the acceleration profile to be a power-law baseline plus a sinusoidal bump:

α(t) = a₀ · [ 1 − (t/L)^q ] − k · sin(π · t / L) α(0) = a₀ ← by construction (baseline = a₀, sin = 0) α(L) = 0 ← by construction (baseline = 0, sin = 0)

Three free parameters: q > 0 (shape), L > 0 (final time), k (bump amplitude).

3 · Integral conditions

The velocity and displacement boundary conditions give two equations:

ω(L) = 0 ⟹ a₀L·q/(q+1) − 2kL/π = −v₀ s(L)−s(0) = Δs ⟹ a₀L²·G(q) − kL²/π = Δs − v₀L

where

G(q) = ½ − 1/((q+1)(q+2)) − q/(2(q+1))

Eliminating k leaves a quadratic in L for each choice of q:

a₀ · G(q) · L² + (v₀/2) · L − Δs = 0

Solve for L, then back out k:

k = (π/2) · ( a₀·q/(q+1) + v₀/L )

4 · Zero-crossing behaviour

Because the baseline a₀[1−(t/L)^q] ≥ 0 for t ∈ [0,L] when a₀ > 0:

  • k ≤ 0 — the sine term adds positively; the whole α(t) stays ≥ 0. Zero crossings on (0, L).
  • k > 0 — the sine term subtracts; if a₀·q < k·π, α dips negative once and returns to 0 at L. One crossing.
  • Otherwise α never reaches 0 inside (0, L). Zero crossings.

By scanning q, we find every (L, k) pair. Solutions with more than one crossing are discarded.

This form automatically satisfies α(0) = a₀ and α(L) = 0. The user's Example 1 (currently unsolvable) becomes solvable on this branch, with q ∈ (0, ≈0.52) and zero crossings. Example 2 (currently solvable with a negative dip) becomes solvable with q ∈ (0, 5) and one crossing.

8 · What this does

You have an acceleration profile that must start at a₀, end at 0 at the final time L, and simultaneously satisfy ω(L) = 0 and s(L) − s(0) = Δs. The old model (A sin(ft+k₁) + k₂) forced a specific frequency relationship that sometimes had no solution — even when a perfectly reasonable monotonic acceleration curve exists.

This solver allows the acceleration to follow a₀[1 − (t/L)^q] − k sin(πt/L). By scanning the shape parameter q over its full range and solving the resulting quadratic for L, it finds every solution with at most one zero-crossing, including the monotonic ones that the old model could never produce.

Selection heuristic

  • First — prefer solutions with zero zero-crossings (monotonic-ish).
  • Second — among those, the smallest final time L wins.
  • If no zero-crossing solutions exist, prefer single-crossing with the smallest L.

When things still go wrong

  • a₀ = 0 — degenerate; excluded.
  • Δs = 0 — displacement must be zero, may have no solution for some signs.
  • Negative discriminant for all q — genuinely no solution in this family (unlikely).
